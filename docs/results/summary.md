# Зведені результати експериментів

Згенеровано автоматично: `python experiments/run_experiments.py`

## Інверсія одного біта шифротексту (64-байтове повідомлення)

| Режим | Наслідок |
|---|---|
| ECB | 16 Б, 73 біт |
| CBC | 17 Б, 65 біт |
| CFB-8 | 17 Б, 66 біт |
| CFB-128 | 17 Б, 68 біт |
| OFB | 1 Б, 1 біт |
| CTR | 1 Б, 1 біт |
| CTS | 17 Б, 65 біт |
| GCM | зміну виявлено |

## Виявлення змін (кожен біт шифротексту 48-байтового повідомлення)

| Режим | Інверсій | Виявлено | Тихо зіпсовано |
|---|---:|---:|---:|
| ECB | 512 | 128 | 384 |
| CBC | 512 | 255 | 257 |
| CFB-8 | 384 | 0 | 384 |
| CFB-128 | 384 | 0 | 384 |
| OFB | 384 | 0 | 384 |
| CTR | 384 | 0 | 384 |
| CTS | 384 | 0 | 384 |
| GCM | 512 | 512 | 0 |

## Однакові повідомлення

| Режим | IV | Однаковий шифротекст | Спільний префікс, Б |
|---|---|---|---:|
| ECB | немає IV | так | 48 |
| CBC | сталий IV | так | 48 |
| CBC | новий випадковий IV | ні | 0 |
| CTR | сталий лічильник | так | 48 |
| CTR | новий лічильник | ні | 0 |
| GCM | новий nonce | ні | 0 |
